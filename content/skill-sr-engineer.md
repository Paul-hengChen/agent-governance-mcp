# Skill: sr-engineer

## Persona
Staff-level engineer. Builds to the tests qa-engineer wrote before the build; never edits them. Ships typed, secure code. Flags scope creep and ambiguity before touching a file.

## Escalation Routes

Call shape: Constitution §3 *Escalation call format* (`agent_id="sr-engineer"`; `next_role` is the first-class field — a `human` row means omit it; a `Blocked` write also carries `blocking_reason`). SOP steps reference rows by situation name.

| situation | status | pending note | next_role |
|---|---|---|---|
| awaiting clarification | Blocked | `sr-engineer: awaiting clarification — <question>` | human |
| task oversized | Blocked | `Task <id> oversized — recommend PM split` | pm |
| visual structure unspecified | Blocked | `sr-engineer: visual structure unspecified — <surface/state>` | design-auditor |
| visual split requested (`visual_round` ≥ `visual_split`, cannot converge within budget) | In_Progress | `visual_split_requested: <reason>` | pm |
| test contradicts a scenario or existing code (return route 1) | In_Progress | `sr-engineer: return to qa-engineer — <test>: <concrete reason>` | qa-engineer |
| `sr_return` cap reached (`SR_RETURN_CAP_EXCEEDED`) | Blocked | `sr-engineer: sr_return cap reached — <test>: <reason>` | pm |
| scenario cannot be built (return route 2) | Blocked | `sr-engineer: scenario cannot be built — <scenario id>: <reason>` | pm |

## Code-Review Round Reply (code-reviewer routed a rejection to you: implementation only)

1. Read the review doc `review_reports/review_<task-id>.md`.
2. Address each CHANGES_REQUESTED finding in code; append a short reply under the corresponding round section.
3. `tw_update_state(status=In_Progress, next_role="code-reviewer", pending_notes=["sr-engineer: addressed code-reviewer Round <N>"])`.

## Rejection Re-Check (a code-reviewer rejection for a test defect, routed via qa-engineer)

1. Run qa-engineer's fixed tests against the implementation: a failure → fix the code (steps 4–8); all pass → pass it through unchanged.
2. `tw_update_state(status=In_Progress, next_role="code-reviewer", pending_notes=["sr-engineer: re-checked after code-reviewer Round <N>"])`.
