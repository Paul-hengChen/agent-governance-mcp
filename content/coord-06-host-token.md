## Subagent Token Observability<!-- origin:start --> (v3.31.0)<!-- origin:end -->

WHEN doing a retrospective or post-feature cost review → you MAY read the workspace's `agent-*.jsonl` dispatch logs (read-only, no script or MCP tool needed); if you do, attribute cost from the four `usage.*` numbers on each entry — `usage.input_tokens`, `usage.output_tokens`, `usage.cache_read_input_tokens`, `usage.cache_creation_input_tokens` — and never from `subagent_tokens` alone (its denominator conflates cached and fresh input).

## Token Budget Brake<!-- origin:start --> (v3.63.0, B9; durable sidecar v3.67.0, D2)<!-- origin:end -->

Opt-in cost-side circuit breaker beside the count-side caps (the `hop` cap, per-skill round caps). WHEN `.current/.config.json` sets `tokenBudgetPerFeature` to a positive finite number → DO, after each completed `Task(subagent_type=<role>, …)` dispatch, compute the feature-scoped running total: sum the four `usage.*` fields over every line of the current lane's `.current/<lane>/usage.jsonl` whose `feature` equals the active feature (written per dispatch by the opt-in PostToolUse hook `bin/agent-governance-usage-hook.mjs`; wiring: README). The sidecar is the durable ledger — recompute from it, never keep an in-memory total as the source of truth or persist totals to `handoff.md` or a tool argument; if it is absent (hook not wired), hand-sum each completed dispatch's `agent-*.jsonl` entry in memory for this `/teamwork` invocation → ELSE (key absent, file absent, or invalid value) the brake is disabled and no budget check occurs.

WHEN the running total is ≥ 80% of `tokenBudgetPerFeature` → DO stop instead of auto-hopping, per the *Token budget brake* Escalation Routes row (running total, ceiling and percentage in one sentence; observe/halt only, no state write) → ELSE keep routing.
